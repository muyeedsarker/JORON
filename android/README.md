# JORON Android App

Native Android UI foundation for JORON, built with Kotlin + Jetpack Compose.

## Brand system
- JORON Green: `#087A62`
- JORON Pink: `#E91E63`
- Soft green/pink pastel surfaces
- Rounded 18–28dp cards and buttons
- Bengali-first typography and copy
- Trust, privacy and relationship-focused visual language

## Screen structure
- Home / Branding
- Login
- Registration
- Dashboard
- Smart Biodata
- Partner Preference
- Smart Matching
- Profile
- Interests
- Secure Chat
- Membership
- Payment
- Help Center
- Privacy & Safety
- Report / Block
- Settings

## Current scope
This first Android pass is a complete navigable UI prototype. Firebase Authentication, Firestore, Storage, FCM, real-time chat, payment verification, moderation and production security are intentionally kept as the next integration layer.

Open `android/` in Android Studio and run the `app` configuration.
