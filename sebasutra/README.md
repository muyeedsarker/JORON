**আপনার প্রয়োজন, এক সূত্রে।**  
Creator By — **Muyeed Sarker**

## Implemented in this branch
- Responsive home/service hub
- SOS emergency action sheet with consent/permission notes
- Emergency directory entry points
- Smart search with service routing
- Blood donor/request entry UI
- First-aid guidance cards
- Snake-bite and animal-bite safety guidance
- Near Me geolocation permission flow
- Train, fare, hotel, weather, prayer and Ramadan service shells
- Family safety and medicine reminder entry points
- Community/help-request moderation concept
- Privacy/profile information
- Mobile bottom navigation

## Demo
Open `app.html` in a browser for the functional single-page prototype.

## Production blockers
This repository branch is a **functional prototype/MVP, not a finished production app**. Production requires a real backend/database, secure authentication, verified emergency contacts, verified health guidance, donor privacy/consent, maps/places provider, live transport data, weather/disaster APIs, prayer calculations, notifications, moderation/admin tooling, automated tests, and Android/iOS packaging. Emergency calling or messaging must respect OS permissions and local laws/policies.
