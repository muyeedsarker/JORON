# সেবাসূত্র Launch Readiness

## Current deliverable
The repository contains a responsive, installable web/PWA prototype covering the planned service categories and safety-oriented UX.

## Not yet production-complete
Production release still requires infrastructure outside this static repository: a secure backend/database, real authentication, verified data providers, donor consent/verification workflows, admin moderation, push notification infrastructure, secrets management, monitoring, native Android/iOS packaging, and real-device/security testing.

## Rule
Do not label the project "production complete" until every item above is implemented and tested. The UI must never fabricate live emergency, medical, transport, weather, hotel, or donor data.
